文本是回忆提纲.

周五

=> 宁波火车站。下面根据小红书攻略走.

=> 天一阁。外围挺好看的，只是刚好快闭馆了。

=> 月湖公园。70 元划船。下小雨了，我们过桥洞打车。错过了城隍历史文化街区，

=> 南塘老街。饿到腿软，吃菜干饼，梭子蟹炒年糕，逛精品店。

=> 沿江步道，下雨了。打车取包，顺风车回黄泽，住宾馆。

周六

=> 十二点多起床，两人吃了黄泽臭豆腐春饼。打车去鹿山广场，逛 GREEN PARTY.

=> 穿越东直街，虽然周六但是没什么人，营销策略显然不如其他城市的网红街。走到老国商。这里一楼是灯光昏暗的清仓甩卖区，许多室内卷帘门缩小了面积，而且似乎有霉味儿。上楼的电梯居然有意被柜子和杂货挡住，完全无法过去，能看到二楼以上是全黑的。这下必有一些无法重建的地图了。

十五年前老国商完全看不出有什么生存问题。我去杭州以后，想必老市中心年轻人越来越少，消费力不足，店面逐渐就搬走了。城区其他地方则是缓慢蠕动中.

=> 在电影和游泳中选择了游泳。打车到游泳馆。

lmz 非常不错，刚开始只能换气 3 次，经过我们反复探索能换 10 次了. 主要问题：

换气后如何防止下半身下沉？ -> 最好需要曲腿后向下踢腿。

换气时如何吸入更多气？

我成功完成两次 50 米蛙泳！花费 90s / 97s，后半程没体力。

打车到东圃铁板烧，由于排队要1小时，先吃了旁边好吃的广东粥-皮蛋瘦肉粥，又找半天电动车去一景乳业门店，买了蓝莓酸奶，还可以！

至于东圃铁板烧，量巨大，有点咸。

由于太晚了无法实施潜行计划，睡酒店。

周日

=> 临近中午起床，找小吃的时候有个老板出来说“对面胖大姐是网红店”。后来发现也许胖大姐是对的。

=> 打车到新昌大佛寺。没几步路给我俩走的累死了。

=> 打车到吾悦广场，吃 555 地带。这个还不错，不过美团套餐比单点更划算。

=> 实施潜行计划。非常困难，首先路边有狗，而 lmz 非常害怕。我必须先安置 lmz 再回家，找了一家面店点便宜面打算让 lmz 就地打发时间，店家却说快要打烊. 我只能先进家里观察。

然而，奶奶说晚饭前已经洗澡，因此如何进家里只能随机应变。先陪奶奶唠嗑以避免异常，lmz 此时消息不畅，而打烊后我暂且建议去理发店洗吹一下，但 lmz 觉得不太方便只能站外面被蚊子咬。

奶奶特能说，而众所周知，我家人在抓我小动作这方面永远智力过人，因此我不敢轻举妄动。我尽量结束话茬子早点上二楼，从而让 lmz 有机会进来。我先洗澡以免 lmz 之后进来后我无法把握奶奶动向。此时我只能指望奶奶找点烧水、电视或者洗衣服的事情干。

然而，lmz 已经被🦟咬烦了，并说要去酒店了，我立刻动用可乐方案：我去翻冰箱找一个不存在的饮料 - 可乐，并说要去小店买，这样先把 lmz 带到家门口。我俩谨慎地来到家门口等待时机，尽管无法避免农村弄堂昏暗吓人以及夜狗巡逻的风险。

我继续在家里吸引奶奶注意力，由于我的长裤恰好刚被奶奶洗了，刚好可以让奶奶帮忙找找明天能穿的外裤。这时候狗运来了，奶奶居然去三楼帮忙找外裤，我赶紧让 lmz 进来，躲在一楼 WC。而另一个狗运的事情是，lmz 刚好 WC 急，可以释放一下。

后面实在没有好机会带 lmz 上二楼，只能催奶奶早点睡觉，匍匐而出带 lmz 上楼。之中困难极多，比如上周的推拉门被换成了吸铁石门帘，松手合上声音巨大。在步步为营做了多种紧急预案之后，总算还是让 lmz 睡上了小床。

周一

早上也是凭借运气让 lmz 没有被发现. 待我奶奶出门以后，我往前探一段，lmz 跟着走一段，我说出去以后我视频指挥你找到一个小店吃饭。到楼梯中间，为了防止出门以后 lmz 走错路，我赶忙回头拿手机，原以为 lmz 会等着我领路，刚好下楼时想起来一楼有可爱小猫，刚准备叫她来看，结果到一楼院子发现 lmz 已经光速出门了，我只能回房间开启视频通话.

可惜了没看见小小猫。我跟奶奶去银行处理存折，居然还撞见了 lmz，十分危险之际，lmz 往路边转身向路边走，最终啥事没有。

由于铁路无法直达诸暨，我们改去绍兴玩。我们酒店出来后，吃完次坞打面，从景区后门穿到正门。

=> 三味书屋. 这里看起来都是仿古重建的，江浙无处不在的老宅格局，没什么特别的。假书屋里面有多个假早字（真迹在博物馆）。

=> 鲁迅祖居。仍然是重建的，比三味书屋大。

=> 鲁迅故居。这里通过关门搞成九曲盘桓的线性游览了，十步一文创店，也是没活整活，导游说只有一间房子是当年的真迹，里面家具只有一张床是鲁迅睡过的。跟我家老床差不多。

=> 其他地方：网红小吃街，还不如嵊州。晚饭肯德基，然后不知道干嘛，遂决定去看蜘蛛侠：崭新之日。

讲真这个荷兰弟和 Jean Gray CP 是真好嗑，双方也是高颜值组合，Jean 这个大眼睛真是好看。毕竟浩克那一段可以看出，Jean 附身的时候是能获得感官反馈，无需质疑 Jean 和荷兰弟算是亲上了。至于赞达亚，她的黑人不屑歪嘴让 lmz 屡屡难受。lmz 表现出出色的推理水平，V-MAX 等多个疑点居然能够预判出现时间，简直看了剧透。而我看电影经常分神回忆，时不时漏一句台词，走马观花，推理能力堪忧。

我之前来过绍兴，很多地方居然确实能认出来，只是上次不辨南北，这次却能分得清方向了。根据小红书的评论，如果上次提早再早几天预约鲁迅故居，当时将会没有那么多文创，走简单的路线。另外绍兴的交通太差了，许多路口竟然没有红绿灯，车不让人，电动车也是横冲直撞，简直是小长沙。

周二：艰难赶高铁。

景区推荐程度：4/10 没有特色！

个人欢乐程度：7/10
